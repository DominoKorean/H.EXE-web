# 하늘 웹 재구현

사용자 지시: 설계 문답 없이 구현. 최신 Chromium Chrome, 터치 없는 데스크톱 우선.

TypeScript, Canvas 2D, 정수 좌표의 16색 프레임버퍼를 사용한다. 원본 자료는
`haneul/`에 보존한다. DOS는 비교용 별도 페이지에만 남긴다. 이 저장소에서 작업하며
외부 배포는 하지 않는다. 구현과 확인된 사실, 아직 검증하지 못한 동작을 구분한다.

- [x] 원본 리소스 및 ART/PCX 디코더: 실제 fixture, 손상 파일, 저장 왕복 테스트.
- [x] 한글 10/4/4 조합형·영문 비트맵 글꼴: 실행 파일 조합표 사용.
- [x] 인덱스 색상 편집 엔진: 선, 도형, 채우기, 선택, 변환, undo/redo 테스트.
- [ ] 640×480 UI: 원본 아이콘·메뉴·팔레트·상태바, 키보드와 마우스, 파일 대화상자.
- [x] Chrome 실제 조작, 빌드·테스트 및 독립 코드 리뷰. README에 동작 범위 기록.
- [x] 웹에서 저장한 ART를 DOS 원본에서 직접 열어 확인.
- [ ] 벡터 글꼴, 글자 모양의 전체 효과와 원본 하위 메뉴.
- [ ] 모든 대화상자, 도형 알고리즘, 커서 및 옵션의 원본 대조.

UI 항목은 기본 화면이 작동하더라도 전체 동일성 검증 전까지 완료로 표시하지 않는다.
구체적인 차이와 분석 오프셋은 `docs/reverse-engineering.md`를 참조한다.

파일: `src/formats.ts`, `src/font.ts`, `src/raster.ts`, `src/editor.ts`,
`src/main.ts`, `src/style.css`; `tools/prepare-assets.mjs`; `tests/*.test.mjs`.

검증 주안점: 손상된 파일을 열 때 기존 작업 보존, 화면 밖 드래그, 가로로 8의 배수가
아닌 PCX, undo 시 팔레트·크기 복원, 한글 IME 조합 중 단축키 차단.

기록: 원본 관찰용 Python 서버는 sandbox 소켓 제한 때문에 권한을 올려 실행.
원본의 HANUL.LOG와 VECTOR.FNT는 텍스트/비트맵이 아닌 MZ 실행 파일이다.
