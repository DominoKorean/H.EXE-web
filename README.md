# 하늘 Web

하늘 3.2를 GPT 6 Astra로 TypeScript로 재작성한 웹 포팅버전입니다.
일부 요소(프린팅)등은 직접 검수가 힘들어 실제 당시 환경과 다르게 작동할 수 있습니다.

---

DOS용 하늘 2.3의 리소스와 파일 형식을 분석해 TypeScript와 Canvas 2D로 다시 구현하고 있습니다.
기본 페이지는 DOS 에뮬레이터, WebAssembly, CDN 없이 실행됩니다. 우선 지원 환경은 최신
Chromium 기반 Chrome의 마우스·키보드 데스크톱입니다.

**현재 상태: 편집 가능한 웹 구현이며, 원본의 모든 UI와 동작이 동일한 완성본은 아닙니다.**
확인한 형식과 남은 차이는 [역공학 기록](docs/reverse-engineering.md)에 구분해 두었습니다.

## 실행

Node.js 22.12 이상이 필요합니다.

```sh
npm install
npm run dev
```

Chrome에서 <http://127.0.0.1:5179/>를 엽니다. 첫 화면과 안내를 클릭하면 편집기로 들어갑니다.
서버는 로컬 주소에만 바인딩합니다. 원본 비교 페이지는
<http://127.0.0.1:5179/reference/index.html>이며, 이 페이지에만 외부 js-dos가 필요합니다.

```sh
npm test
npm run build
npm run preview
```

`dist/`가 정적 배포 결과입니다. 상대 경로로 빌드하므로 하위 디렉터리에도 놓을 수 있습니다.
`file://`로 열지 말고 HTTP 서버로 제공하세요. 서버에 사용자 그림을 업로드하는 기능은 없습니다.

## 구현된 동작

- 원본 시작 그림, 도구 아이콘, 메뉴 아이콘, 16색 팔레트, 하늘소 로고, 조합형 한글 글꼴.
- 직선·자유 곡선·사각형·입체 상자·원·타원·채우기·분무기·붓, 선 무늬와 두께.
- 범위 선택, 복사·이동·지우기, 반전·좌우/상하 뒤집기·90도 회전·크기 변경.
- 비트맵 한글 7종과 영문 5종, 글자 확대와 진하게, 브라우저 한글 입력.
- ART/16색 PCX 열기와 저장, 부분 그림, PNG 내보내기, 브라우저 인쇄.
- 실행 취소/다시 실행, 스크롤바 드래그, 확대, IndexedDB 작업 임시 보관과 재접속 복원.

## 조작

| 입력 | 동작 |
| --- | --- |
| 왼쪽 드래그 | 선택한 도구로 그리기 |
| 오른쪽 드래그 | 편집 범위 선택 |
| 색상 왼쪽/오른쪽 클릭 | 그리기 색/지우기 색 지정 |
| Alt+클릭 | 그림에서 색 고르기 |
| 휠 / Shift+휠 | 세로 / 가로 이동 |
| F1 / F2 / F3 / F9 / F10 | 도움말 / 저장 / 열기 / 감상 / 차림표 |
| Alt+G | 글쓰기 위치를 클릭하고 입력, Enter 확정, Esc 취소 |
| Alt+U 또는 Ctrl+Z / Ctrl+Y | 실행 취소 / 다시 실행 |
| Ctrl+C / Ctrl+V | 복사 / 붙여넣기 위치 지정 |
| Ctrl+A / Delete | 전체 범위 / 범위 지우기 |
| Ctrl+S | 원본 메뉴의 음향 효과 켜기/끄기. 저장은 F2 |
| Ctrl+P / Alt+P | 프린터 기종·해상도 / 전체 찍기 |
| Shift+F1 | 웹 버전 조작법 |
| Esc | 진행 중인 그리기·이동·대화상자 취소 |

F3 창의 파일 목록은 동봉 예제입니다. `D` 드라이브를 누르면 컴퓨터의 ART/PCX 파일을 고를 수 있습니다.
출력 → 전체 찍기 → 인쇄를 누르면 웹 팝업에서 Chrome 인쇄 창을 열거나 원래 색 그대로 PNG를 저장할 수 있습니다.
파일은 브라우저 안에서 읽고, F2로 저장하면 다운로드됩니다. 임시 보관은 마지막 그림 한 개이며
브라우저 데이터 삭제 시 없어집니다. 실행 취소 기록은 새로 접속하면 초기화됩니다.

ART는 원본 형식의 제한 때문에 가로가 8의 배수이고 총 524,280픽셀 이하여야 합니다.
이외의 크기는 PCX로 저장할 수 있습니다. PCX는 1비트×4플레인 16색 형식을 지원합니다.

## 검증 기록

2026-11-17: 자동 테스트 19개, TypeScript 검사와 Vite 빌드 통과.
실제 Chrome에서 시작, 원본 ROSE.ART 읽기, 스크롤바 드래그, 직선과 실행 취소,
한글 입력, ART 다운로드·다시 열기, 새 탭에서 임시 보관 복원을 확인했습니다.
웹에서 입력한 `하늘 그림틀 2026`을 저장한 ART가 **DOS 원본 H.EXE에서도 표시됨을 확인**했습니다.
이 검증은 단일 640×480 비압축 ART 사례이며 모든 파일에 대한 호환성을 보증하지 않습니다.

원본 호환 검증용 묶음을 만들려면 다음 명령을 사용합니다. 원본 자료는 변경하지 않습니다.

```sh
node tools/verify-export.mjs /absolute/path/to/export.ART
```

개발 서버에서 `/artifacts/compat.html`을 열고 원본의 F3에서 `WEBTEST.ART`를 선택합니다.

## 원본 자료

`haneul/`, `haneul.jsdos`, 기존 `build-bundle.js`는 보존했습니다.
원본 안내에 있는 하늘소의 제작자 표시와 상업적 이용 제한을 유지합니다.
재구현 코드가 원본 그림·아이콘·글꼴의 권리 조건을 바꾸지는 않습니다.
